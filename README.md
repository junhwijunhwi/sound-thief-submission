# 소리 도둑

Windows에서 Python과 pico2d로 실행하는 턴제 잠입 퍼즐입니다. 경비를 피해 소리 병을 챙긴 뒤 출구로 돌아오면 성공합니다.

## 실행

VS Code에서 이 폴더를 열고 터미널에서 실행합니다.

```powershell
python -m pip install -r requirements.txt
python main.py
```

## 1주차 테스트 맵

- WASD 또는 방향키로 한 칸 이동합니다. Space로 한 턴 대기하고, R로 재시작합니다. 벽에 막힌 입력은 턴을 소비하지 않습니다.
- 일반 바닥에 발을 디디면 발소리가 통로를 따라 최대 4칸까지 퍼집니다. 카펫으로 이동하거나 대기하면 소리가 나지 않습니다.
- 청각형 경비는 매 턴 한 칸 움직입니다. 소리를 들으면 마지막으로 들은 위치를 조사한 뒤 기존 순찰 경로로 복귀합니다.
- 경비와 같은 칸에 들어가거나 경비가 내 칸으로 이동하면 실패합니다.
